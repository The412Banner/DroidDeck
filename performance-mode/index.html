DD 0.6.0 Stable and now

DroidDeck's performance fixes stop DroidDeck, gamescope and Wine from waiting on each other every frame, and with PR #1697 Windows games get the fastest core as CPU 0. The first fixes started as the Performance mode switch; since PR #1650 every session runs that way, and Steam's Frame Limit in the Quick Access menu is the only frame limit.
